# Product Strategy

## Workflow

1. Read `docs/00-product-brief.md` and `docs/01-mvp-scope.md`.
2. Tie every proposed feature to a real travel-planning pain point.
3. Prefer trip decision support over generic chatbot behavior.
4. Separate inspiration, planning, feasibility, booking, and lead capture.
5. Define a measurable success metric for each feature.

## Product Rules

- Do not pitch LangGraph or multi-agent as the user-facing value.
- The value is feasible itinerary, cost clarity, route sanity, risk warnings, and next action.
- TikTok and Google are inspiration sources; the product should convert inspiration into an actionable trip.
- Treat Decision Engine work as a product differentiator.

## Useful Checks

- Would a user still need this if they already saw TikTok videos?
- Does the feature help decide, book, share, or revise a trip?
- Can the result be verified by data or deterministic rules?
